# 登录鉴权接入

## 当前状态

目前已完成与数据库无关的权限策略及测试：

- 登录回跳仅接受本站路径，拒绝站外 URL、编码绕过和登录循环。
- 管理员判定默认拒绝，仅接受服务端会话核验过的用户 ID 与服务端配置的 ID 精确匹配。
- 不使用昵称、用户自行填写的邮箱、浏览器存储或客户端传入的角色判断管理员身份。

这些策略尚未接入页面。当前线上 `/login`、`/register` 仍是演示，`/admin` 尚未启用真实鉴权。账号存储与服务端会话实现需要先确定数据库配置。

## 本次实现范围

1. 现有邮箱密码表单接入真实注册与登录，提供加载、错误和成功状态。
2. 账号、密码哈希和可撤销会话保存在服务端数据库；使用成熟鉴权库实现密码校验和会话管理。
3. 使用 HttpOnly Cookie 保持登录，支持退出并撤销会话，过期后重新登录。
4. `/admin` 在服务端验证身份和管理员权限；匿名用户跳转登录，普通账号不能访问。
5. 导航按服务端确认的登录状态显示账号、退出按钮及管理员入口。
6. 验证来源检查、登录限流、过期/撤销会话和普通用户越权场景。

普通注册用户默认不具有管理员权限。站长账号完成创建并核验后，再由部署环境配置其不可变用户 ID，不采用“第一个注册用户自动成为管理员”的规则。

文章、相册、留言等内容继续遵循原有的浏览器本地存储模式；本次账号数据库接入不代表这些内容已实现跨设备同步。将来新增内容写入接口时，每个接口都必须独立核验服务端权限。

## 待确定的配置

- 数据库类型与服务商。
- 部署位置：本机、云服务器或托管数据库。
- 数据库名称以及服务端可用的连接方式。
- 站长账号邮箱，用于后续账号创建和身份核验。

当前线上运行在 Sites 的 Cloudflare Workers 环境，支持 D1 绑定或可通过 HTTP 访问的外部数据库服务。普通本机数据库地址不能直接作为线上连接地址；需要根据实际环境确定后端接入方式。

数据库密码、连接密钥和鉴权密钥不得写入源码、公开文档或 Git 历史。选定数据库后再提供匹配的本地配置示例，并通过托管环境的密钥配置接入生产值。

邮箱验证码、邮件验证与密码找回还需要邮件发送服务；在接入前不提供无法完成的找回操作。

## 验证与发布

运行 `npm run test:auth` 检查回跳策略和管理员判定边界，运行 `npm run lint` 检查类型与代码质量。

连库后补充注册、密码登录、退出、会话撤销、管理员授权和访问拒绝的实际接口测试；通过生产构建后，按功能提交到用户指定的 GitHub 仓库，再更新线上站点。
