# PVL随记

PVL 的综合个人主页，默认使用中文，记录学习、生活、照片和随笔。

> 过去无可挽回，未来可以改变。

在线地址：[https://pvl-notes.hl7894687.chatgpt.site](https://pvl-notes.hl7894687.chatgpt.site)

## 已实现功能

- 沉浸式首页：深绿雨夜、背景视觉、雨滴和粒子动效、明暗主题、减少动态效果适配
- 博客系统：Markdown 与 GFM 渲染、全文搜索、置顶文章、分类、标签和归档
- 随笔与相册：点赞持久化、相册筛选、照片大图预览
- 社区页面：友链申请与审核、留言发布、弹幕墙、楼中回复
- 内容页面：更新日志、关于页、真实本机访问统计与趋势图
- 独立后台：站点资料、文章、随笔、相册、友链、留言和更新日志管理
- 数据中心：完整 JSON 导入、导出和初始数据恢复
- 账号鉴权：真实邮箱密码注册与登录、数据库会话、退出登录和站长后台权限检查（需先配置本地账号服务）
- 响应式布局：桌面、平板和手机均可使用

## 本地运行

环境要求：Node.js 24 或更高版本、本机 MySQL。账号服务配置见 [登录鉴权接入](./docs/authentication.md)。

```bash
npm install
# 首次运行请先按鉴权文档填写本地配置、迁移表结构并初始化站长。
npm run auth:dev
```

保持账号服务运行，在另一个终端启动网站：

```bash
npm run dev
```

生产构建：

```bash
npm run build
```

前台地址为 `http://localhost:3000`，独立后台为 `http://localhost:3000/admin`。

## 当前数据模式

账号、密码哈希、会话和登录限流使用 MySQL；文章、相册、留言等内容暂时仍通过统一 Repository 数据层读写浏览器 `localStorage`。两者相互独立：

- 数据不会自动跨浏览器或跨设备同步。
- 清理浏览器站点数据会删除本地修改，建议定期从后台导出 JSON。
- 访问统计按浏览器会话去重，只代表当前浏览器，不代表全站总量。
- `/login` 与 `/register` 请求服务端创建或验证账号；浏览器存储中不保存账号密码或会话令牌。
- `/admin` 在服务端确认站长身份。普通注册用户没有后台权限；账号服务未配置或不可达时，后台保持关闭。
- 站长登录不同浏览器后，看到的内容仍是该浏览器内的本地数据，不会因此自动同步。

后续迁移内容数据时，可以保留现有页面与数据类型，新增远程 Repository 实现并进行一次 JSON 数据迁移。新增内容写入接口必须独立验证权限。

仓库中的鉴权代码与线上发布状态不同：本机 MySQL 与登录鉴权链路已完成联调，当前线上仍保留此前的可视化版本。本机账号服务只监听本机地址，不能直接被 Sites 云端访问；完成生产后端配置后再发布鉴权版本。

## 私人配置

`.env.auth`、`.dev.vars`、`.auth-admin.json` 以及数据库导出文件均被 Git 忽略。仓库只提供通用 `.example` 模板；不要将数据库密码、站长初始密码或服务密钥填入模板、源码、公开文档或提交记录。

## 更换个人素材

打开 `/admin`，进入“站点设置”，即可替换昵称、简介、头像、首页背景和内容页背景。初始图片是可替换的占位素材，详细来源见 [CREDITS.md](./CREDITS.md)。
